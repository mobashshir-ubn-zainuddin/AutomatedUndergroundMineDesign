Powered by Advanced Technologies

Seven integrated modules that transform raw geological data into an optimized, risk-assessed mine design — all in a single platform.

📊

Synthetic Block Model

Generates geologically realistic 3D block models with two ore zones using Gaussian distance functions and spatially correlated grade fields — mimicking real deposit geometry and grade continuity.

💰

Economic Evaluation

Classifies every block as ore or waste using the breakeven cutoff grade formula. Calculates per-block economic value from tonnage, grade, recovery, gold price, and all-in sustaining costs.

PandasEconomic Modeling
⛏

BILP Stope Optimization

Binary Integer Linear Programming selects the profit-maximizing set of non-overlapping stopes. A floating stope algorithm generates thousands of candidates; the solver proves mathematical optimality.

PuLP 4.xHiGHS
🏗

Development Network

Algorithmically generates decline access, level drives along strike, and crosscuts to every selected stope. Automatically estimates per-metre development costs across all mining levels.

Monte Carlo Simulation

Runs 1,000+ NPV simulations under simultaneous uncertainty in gold price, grade, and operating costs. Produces full risk profiles with P10–P90 percentiles and tornado sensitivity charts.

How It Differs from Industry Practice

Traditional underground mine design relies on sequential manual workflows across disconnected software. This platform integrates the full chain into one automated, real-time pipeline.

Aspect Traditional Practice MineOptima
Stope Layout Manual placement by experienced engineers using rules of thumb in Surpac/Deswik — iterative trial-and-error over days or weeks BILP optimization with mathematically provable optimal solution; exhaustive candidate search guarantees maximum extracted value
Grade Estimation Kriging or Inverse Distance Weighting from drillhole data with limited uncertainty quantification Random Forest with spatial features achieves R² = 0.978; tree variance gives per-block uncertainty for resource classification
Risk Analysis Deterministic single-scenario NPV; manual sensitivity for a few key variables 1,000-iteration Monte Carlo with simultaneous price, grade, and cost variation; full NPV distribution with P10–P90 and tornado charts
Workflow Sequential disconnected tools — Surpac → spreadsheets → Whittle/COMET — each step requiring specialist input Integrated pipeline where changing one parameter (e.g. gold price) cascades through the entire design; single interface
Iteration Speed Days to weeks per complete design iteration; major parameter changes require restart Under 60 seconds for the full pipeline; real-time parameter exploration via web dashboard
Visualization Specialized CAD software (Surpac, Vulcan, Leapfrog) requiring expensive licenses and training Browser-based interactive 3D visualization accessible to any stakeholder — no installation required
Reproducibility Design quality depends on individual engineer experience; difficult to audit decision rationale Fully deterministic given parameters; every design decision traceable to an optimization objective or algorithm
